# Побег из СевГУ

Курсовой проект по ООП: 3D-хоррор от первого лица на C++ и raylib.

## Скачать игру

Готовая версия для Windows: [EscapeFromSevSU-v1.0-windows.zip](https://github.com/mediclp/EscapeFromSevSU/releases/download/v1.0/EscapeFromSevSU-v1.0-windows.zip) ([все версии](https://github.com/mediclp/EscapeFromSevSU/releases)). Распакуйте архив целиком и запустите `EscapeFromSevSU.exe`, устанавливать ничего не нужно. Если Windows покажет предупреждение SmartScreen, нажмите «Подробнее» → «Выполнить в любом случае».

## Сборка из исходников

Откройте папку проекта в CLion как CMake-проект и запустите цель `EscapeFromSevSU`.
raylib скачается сам при первой сборке, нужен интернет. Тесты логики лежат в цели `game_tests`.

Управление: WASD — ходьба, мышь — обзор, Shift — бег, F — фонарик, E — взять или открыть, Esc — пауза, F11 — во весь экран. Справка открывается в меню клавишей H.

Очки: ключ или пропуск 50, записка 20, батарейка и энергетик по 10, пройденный уровень 100. В конце игры добавляется по одному очку за каждую секунду быстрее 600 секунд. Если героя поймали, очки за текущий уровень сгорают.

## Карты

Уровни лежат в `assets/maps/level1.txt` … `level3.txt`. Их можно править в блокноте. Все три уровня — этажи главного корпуса СевГУ: три корпуса буквой Y (А — левый, Б — правый, В — нижний), центральное звено и треугольная шахта с двумя лифтами. Один символ карты — 1 метр, карта может быть до 96×96 символов.

- **Уровень 1, 1 этаж.** Найти электронный пропуск и пройти через турникет у выхода слева от звена.
- **Уровень 2, 2 этаж, и уровень 3, подвал.** В каждом корпусе средний кабинет по левую руку (если смотреть на звено) — лестница. Хватит любого ключа от лестницы, но ключ от корпуса лежит в другом корпусе: от А — в Б, от Б — в В, от В — в А.

Лифты не работают: света в университете нет, это декорация.

| Символ | Значение |
|---|---|
| `#` | стена |
| `w` | стена с окном на улицу |
| `.` | пол |
| `d` | дверной проём: проходимый, над ним стена-перемычка |
| `P` | старт игрока |
| `E` | монстр |
| `a` `b` `v` | ключ от лестницы корпуса А, Б, В |
| `c` | электронный пропуск |
| `B` | батарейка |
| `N` | записка |
| `1` `2` `3` | дверь на лестницу корпуса А, Б, В, открывается своим ключом |
| `T` | турникет, открывается пропуском |
| `L` | лифт, декорация, не открывается |
| `X` | выход: улица или лестница |

Кроме предметов с карты, на каждом уровне случайно появляются два бонуса: батарейка или энергетик.

После правки карты запускайте `game_tests`: тест проверяет, что до предметов можно дойти, а каждый выход закрыт дверью или турникетом.

## Рекорды

После победы результат записывается в `records.txt` рядом с `.exe`. Файл хранит 10 лучших результатов, а 5 из них видны в меню. Если файл испорчен, в меню появляется сообщение об ошибке.

## Классы

| Класс | Файлы | Что делает |
|---|---|---|
| `game_object` | `game_object.h` | абстрактная база: позиция, виртуальные `update()` и `draw()` |
| `flashlight` | `flashlight.*` | фонарик: заряд, включение, разряд |
| `player` | `player.*` | герой: наследует `game_object` и `flashlight`; движение, выносливость, ключи, очки |
| `enemy` | `enemy.*` | абстрактный монстр: патруль → заметил → погоня → потерял → поиск |
| `item`, `key`, `battery`, `energy_drink`, `note` | `item.*` | предметы |
| `door` | `door.*` | дверь на лестницу или турникет, открывается своим ключом |
| `grid_map`, `cell` | `grid_map.*` | сетка уровня: стены, столкновения, видимость, поиск пути |
| `level` | `level.*` | абстрактный уровень: загрузка карты и объекты |
| `level1` + `listener_enemy` | `level1.*` | 1 этаж и его монстр, который слышит бег |
| `level2` + `light_hunter_enemy` | `level2.*` | 2 этаж и его монстр, который идёт на свет |
| `level3` + `warden_enemy` | `level3.*` | подвал и его монстр, который видит вблизи и слышит бег |
| `record` | `record.*` | таблица рекордов в файле |
| `renderer` | `renderer.*` | отрисовка в 480×270, шейдер света и тумана |
| `game` | `game.*` | главный цикл, экраны, уровни, очки, воздушная тревога |
| `clamp_value<T>` | `clamp.h` | шаблон: держит значение в пределах |

Шрифт DejaVu Sans Mono лежит в `assets/fonts`, его лицензия находится там же.
